# بوت Telegram لعمليات ربط بيانات الاتصال في TikTok

> **حالة المشروع:** هذه الوثيقة تصف ما يظهر في ملفات المصدر فقط. لم يُشغّل المشروع أو تُثبت اعتمادياته أو تُنفّذ اختباراته. وتُشير مراجعة المصدر إلى خلل أقواس ظاهر في `bot.py` قد يمنع بدء التشغيل؛ لذا لا توجد هنا تعليمات تشغيل مؤكدة.

## نبذة

مستودع Python يحتوي على بوت Telegram وطبقة طلبات تتصل بواجهات TikTok لإجراءات متعلقة بربط رقم الهاتف أو البريد الإلكتروني وفك ربطهما. تظهر في المصدر تدفقات تحقق عبر رموز وتذاكر وجلسة حساب، إلى جانب توليد تواقيع وبيانات جهاز للطلبات. هذا وصف للوظائف الموجودة في المصدر، وليس تأكيدًا على نجاحها أو اكتمالها.

هذا المشروع يتعامل مع تغييرات حساسة في معلومات اتصال الحساب. لا تستخدمه إلا على حساب تملكه أو لديك تفويض صريح لإدارته، وبعد مراجعة شروط Telegram وTikTok والقوانين المحلية. لا تستخدمه للوصول إلى حسابات الآخرين أو تجاوز وسائل الحماية.

## الوظائف الظاهرة في المصدر

- واجهة محادثة Telegram مبنية على معالجات وأزرار وحالات للمحادثة.
- مسارات للتعامل مع ربط رقم هاتف أو بريد إلكتروني، ومسارات منفصلة لفك الربط.
- استدعاءات HTTP إلى خدمات TikTok، مع تجهيز معلمات الطلب وتواقيع ورؤوس اتصال.
- أدوات مساعدة لتوليد بيانات جهاز ووقت ومعرّف تتبع، واستخراج بعض الحقول من استجابات الخدمة.
- أمر بدء وإلغاء لتدفقات المحادثة.

لا يثبت وجود هذه المسارات أن واجهات TikTok ما تزال متوافقة أو أن كل التدفقات تعمل. ولا توثق الملفات سلوكًا إنتاجيًا أو ضمانات لاستعادة الحساب عند فشل العملية.

## بنية المستودع

- `main.py` — يستدعي نقطة الدخول في `bot.py`.
- `bot.py` — معالجات Telegram وحالات تدفقات المحادثة.
- `states.py` — تعريف حالات التدفقات.
- `tiktok_api.py` — طلبات TikTok وتجهيز التواقيع.
- `utils.py` — دوال مساعدة.
- `config.py` — إعداد يتضمن المتغير `TOKEN`.
- `requirements.txt` — قائمة الاعتماديات المعلنة.

لا يحتوي جذر المستودع المفحوص على README أو ملف ترخيص.

## المتطلبات والإعداد

تعلن `requirements.txt` عن الاعتماديات التالية:

- `python-telegram-bot` بالإصدار `20.7`.
- `requests` بالإصدار `2.31.0`.
- `hsopyt`.
- `tiktok-signature`.

يستورد المصدر وحدات من `hsopyt`، لكن وجود اسم اعتماد في الملف لا يؤكد وحده توافره أو توافق إصداره أو قابلية تثبيته. ولا تحدد الملفات إصدار Python مدعومًا أو خطوات إعداد موثقة.

يعتمد المصدر على `TOKEN` في `config.py`. لا تضع قيمة هذا المتغير أو أي رمز أو كلمة مرور أو بيانات جلسة في المستودع أو سجل المحادثة؛ أعد النظر في تخزينه واستخدم مدير أسرار مناسبًا عند تطوير المشروع. لا يتضمن هذا الملف أي قيمة اعتماد.
